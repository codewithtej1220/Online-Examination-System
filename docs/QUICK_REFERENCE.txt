┌─────────────────────────────────────────────────────────────┐
│ TROUBLESHOOTING                                             │
└─────────────────────────────────────────────────────────────┘

Port Already in Use:
  netstat -ano | findstr :5000
  taskkill /PID <PID> /F

MySQL Not Running:
  net start MySQL80

Module Not Found (Python):
  cd ai-service
  pip install -r requirements.txt

Module Not Found (Node):
  npm install

Clear Everything and Reinstall:
  rm -rf node_modules package-lock.json
  npm install
  cd ai-service
  pip install -r requirements.txt --force-reinstall

┌─────────────────────────────────────────────────────────────┐
│ DEVELOPMENT TIPS                                            │
└─────────────────────────────────────────────────────────────┘

Hot Reload:
  - Frontend: ✓ Automatic (Vite)
  - Backend: ✗ Manual restart needed
  - AI Service: ✗ Manual restart needed

Enable Backend Auto-Reload:
  npm install -g nodemon
  nodemon server.js

View Logs:
  - Check each terminal window
  - Backend logs: console output
  - AI service logs: console output

Database Changes:
  mysql -u root -p online_exam_system
  > SHOW TABLES;
  > SELECT * FROM users;


┌─────────────────────────────────────────────────────────────┐
│ PRODUCTION DEPLOYMENT                                       │
└─────────────────────────────────────────────────────────────┘

Build:
  npm run client:build

Deploy Backend:
  NODE_ENV=production node server.js

Using PM2:
  npm install -g pm2
  pm2 start server.js --name oes-backend
  pm2 start "npm run client:dev" --name oes-frontend
  pm2 save
